# aliaksandr-andronchyk.github.io

Персональный сайт на GitHub Pages: https://aliaksandr-andronchyk.github.io

`index.html` – главная с контактами и ссылкой на приложение в App Store. Из неё ведут
страницы под отдельные специальности, каждая в своей папке со своим `index.html`,
скриншотами и `cv.pdf`: ios-developer, macos-developer, mobile-voice-ai,
ios-test-automation, release-engineer, browser-automation, backend-node, data-pipeline,
telegram-bot, ai-agent-mcp, founding-ios, prototype-engineer, 3d-interface.

Смысл разбивки: под отклик даётся ссылка на ту страницу, которая совпадает с ролью
в объявлении, а не общая главная.

Сборки и зависимостей нет. Правка html и есть правка сайта: коммит в main публикуется
Pages сам. Локально достаточно открыть нужный `index.html` в браузере.
