Prototype Agent

Support and privacy for the iOS app.

What the app is

Prototype Agent is a guest window into the working AI agent of Aliaksandr Andronchyk, an engineer based in Warsaw. You type a question, the app sends it to a small server, the server asks a large language model and sends the answer back.

Guest mode is deliberately limited: the agent has no access to personal files, accounts or private memory, and it cannot act on anything outside the conversation.

Support

Questions, bugs and feature requests go to Andronchyki@icloud.com. Answers usually come within a day.

If the app says the agent is unreachable, the server is temporarily down: it is a single machine, not a data centre. Pull to refresh and try again later.

Privacy

  • The app asks for no accounts, no sign-in and no personal data.
  • It collects no analytics, shows no ads and contains no trackers.
  • Your messages are sent to the server so the model can answer them, and are passed on to the model provider for that single request.
  • The conversation lives in the app while it is open. The server keeps a short technical log of request time and daily usage counts, without message contents.
  • Nothing is sold or shared with third parties beyond the model provider needed to answer.

Do not send confidential or personal information to a guest agent. Treat it as a public demo.

Limits

All users of the app share one daily quota. When it runs out the agent stops answering until the next day. This keeps a personal server affordable.
